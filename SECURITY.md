# Security Policy

If you believe you have found a security issue related to this package, do not post the full details in a public issue first.

Use one of these channels:

- Open a private security report through the repository security workflow if it is enabled.
- Contact the maintainers through the repository owner account.
- If the issue is related to Aspose.Email product behavior rather than this open-source package wrapper, use the Aspose support forum: <https://forum.aspose.com/c/email/9>

When reporting an issue, include:

- affected package version
- Python version
- operating system
- minimal reproduction steps
- whether the issue affects parsing, serialization, or generated output
