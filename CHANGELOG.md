# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog.

## [26.3] - 2026-03-15

First public release.

### Added

- Conversion to and from standard [`email.message.EmailMessage`](https://docs.python.org/3/library/email.message.html#email.message.EmailMessage).
- Typed `PropertyId` helpers for common MSG properties.
- Outlook-oriented authored-message compatibility defaults for new `.msg` files.
- Publishable examples and self-contained tests.

### Changed

- PyPI metadata and package naming aligned with `Aspose.Email FOSS for Python`.
- README and packaging documents updated for GitHub and PyPI publication.
